This action adds an existing product to an opportunity (creates an opportunity product line).

**Workflow Step Name:** Create Opportunity Product

## Inputs
| Name | Type | Required | Description |
| --- | --- | --- | --- |
| Opportunity | Lookup (Opportunity) | Yes | The opportunity to add the product to. |
| Existing Product | Lookup (Product) | Yes | The product. |
| Unit | Lookup (Unit) | Yes | The product unit. |
| Quantity | Decimal | Yes | The quantity. |

## Notes
- Requires Dynamics 365 Sales; not part of the Power Platform version.
