This action creates a quote from an opportunity, including its products (GenerateQuoteFromOpportunity).

**Workflow Step Name:** Create Quote From Opportunity

## Inputs
| Name | Type | Required | Description |
| --- | --- | --- | --- |
| Opportunity | Lookup (Opportunity) | Yes | The opportunity to create the quote from. |

## Outputs
| Name | Type | Description |
| --- | --- | --- |
| Quote | Lookup (Quote) | The new quote. |

## Notes
- Requires Dynamics 365 Sales; not part of the Power Platform version.
